# 🧠 Evaluación Práctica – AgroTech Solutions S.A.

## 📘 Descripción del Proyecto
Este proyecto corresponde al **Taller / Examen Práctico – Progreso 1 (P2)** de la asignatura *Integración de Sistemas*.

El objetivo fue implementar **tres patrones clásicos de integración** usando **Apache Camel** y **Maven**, para simular el flujo de información entre los sistemas **SensData**, **AgroAnalyzer** y **FieldControl**.

Los patrones implementados son:
1. **File Transfer** – transferencia de datos en formato CSV a JSON.  
2. **Shared Database** – almacenamiento y consulta de lecturas en una base de datos compartida (SQLite).  
3. **RPC Simulado (Remote Procedure Call)** – comunicación síncrona entre cliente y servidor.

---

## ⚙️ Tecnologías Utilizadas
- **Java 21**
- **Apache Camel 4.7.0**
- **Maven 3.9.11**
- **SQLite (mediante JDBC)**
- **VS Code / IntelliJ**
- **SLF4J Simple Logger**
